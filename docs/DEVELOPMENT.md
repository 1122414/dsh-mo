# 开发说明

## 模块

- `core.ts`：区间并集/交集、班次与午休、月工作日、逐日指标。纯函数。
- `tracker.ts`：每会话连续执行门槛、已确认时间段、并发合并、采样空洞与时钟倒退保护。
- `adapter.ts`：DSH 公开 UI 状态与连接 generation 的结构化适配；失配停止，不抓 DOM。
- `storage.ts`：schema 版本、严格读取、90 天保留、异常数据保护。
- `app.ts`：记录锁、生命周期、采样/保存、设置与导出，协调其他模块。
- `ui.ts`：独立 Shadow DOM 浮窗，不依赖 DSH 内部 React/UI 布局。
- `plugin.ts`：Cordis 生命周期与页面内单例；`lib/index.js` 为无副作用 Host 占位。
- `preview/`：独立可控的 DSH 契约夹具，加载同一份 `lib/client.js`。

## 不变量

区间采用 epoch 毫秒 `[start,end)`。5 秒是持续自主执行门槛，不是每次工具调用门槛。有效计量按多会话并集，工资按并集与班次交集。只从两个相邻可靠观测推断时间，空洞超过 15 秒不插值；最后一次确认后的断线时间不补记。

多页记录依赖浏览器 Web Locks 的排他锁。未持锁时不订阅状态、不得保存设置或记录。存储和锁不可用时不悄悄降级成可能重复记账的模式。读取未知版本/坏 JSON 时禁止覆盖，只能导出和明确重置。

保存的只有设置与合并区间，不存 session id、对话或工具参数。当前设置重算历史金额是显式产品限制；后续需要费率快照时升级 schema，而不是暗改旧字段意义。

## 构建

精确依赖 TypeScript 5.8.3。默认检查不需要 Vitest、浏览器或模型；使用 Node 内置 test runner。`scripts/build.mjs` 从 `.build` 的 CommonJS 输出构建闭合模块表，生成 DSH loader facade；不会导入远程代码。`lib/` 必须与源码一起提交。

当前容器使用已安装的精确版本编译器，未进行联网 npm 安装。仓库暂未生成 lockfile；后续联网开发环境可正常 `npm install` 生成并提交锁文件。
